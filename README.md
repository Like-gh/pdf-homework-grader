# PDF 作业批改助手

一个给老师用的**桌面小程序**：批量批改学生交上来的 PDF / 图片作业，在页面上直接打勾、打叉、写评语、算分，批改完一键导出：

- 带批注的 PDF 压缩包（可直接传回 Canvas / Moodle，学生能看到批注）
- 更新后的 Canvas 成绩单 CSV（分数自动填进对应作业列）

只在你自己电脑上跑，**不需要服务器、不联网、学生数据不出本机**。基于 PyQt6 + PyMuPDF。

---

## 它能帮你做什么

| 场景 | 它怎么帮你 |
|------|-----------|
| 学生交了 PDF 或手机拍照的图片 | 自动排序、逐份打开；图片会先转成规范 PDF 再批 |
| 要一份份打勾/叉、写评语、给分 | 点一下就是一个标记，总分实时算好 |
| 一批作业今天没批完，明天继续 | 自动记住进度和每份的批改痕迹，打开接着批 |
| 交了很多次作业，怕串档 | 按"批次"隔离，每次作业的记录互不干扰 |
| 批完要回传 + 登记成绩 | 一键导出 ZIP + 自动把分数写进 Canvas 成绩单 |

## 一、安装

需要 Python 3.9 或更高版本。打开终端（命令行），进入项目文件夹后运行：

```bash
pip install -r requirements.txt
```

这会安装两个依赖：

- `PyMuPDF` —— 读取和导出 PDF
- `PyQt6` —— 软件的图形界面

---

## 二、准备作业文件夹

把所有学生的作业文件放进**同一个文件夹**，比如：

```
我的作业/
├── 20230001_张三_作业1.pdf
├── 20230002_李四_作业1.pdf
└── 20230003_王五_作业1.jpg     ← 图片也可以
```

两个关键约定：

1. **文件名开头是学生标识**（学号 / SIS Login ID / ID 都行）。导出成绩时，软件靠文件名开头的这段数字把分数对上学生。用下划线 `_` 分隔，例如 `20230001_张三_作业1.pdf`。
2. 支持 PDF，也支持 JPG / PNG / BMP / WEBP / GIF 图片（会自动转成单页 PDF）。

> 从 Canvas / Moodle 下载的作业压缩包，解压后通常已经自带这种格式的文件名，直接用即可。

## 三、启动和使用

在项目文件夹里运行：

```bash
python src/main.py
```

### 1. 选择作业目录

点工具栏的 **设置路径**，选中上面准备好的作业文件夹。软件会自动列出里面所有 PDF / 图片，并按文件名排序。

### 2. 逐份批改

用鼠标在页面上点击来打分。左侧是工具栏：

| 按钮 | 快捷键 | 作用 |
|------|--------|------|
| 勾 | `T` | 打勾（答对） |
| 叉 | `C` | 打叉（答错） |
| 半勾 | `B` | 半对（勾加一撇） |
| 计分 | `S` | 按选定分值直接落笔（如 +5 分） |
| 擦除 | `E` | 删掉最近的标记或评语（右键点击也可） |
| 评语 | — | 在点击处写下评语，可选预设或自定义 |

- **换下一位学生**：`Ctrl+N`；上一位 `Ctrl+P`；第一位 `Ctrl+F`；最后一位 `Ctrl+L`
- **跳到下一位还没批的**：`Ctrl+G`
- **翻页**：`Ctrl+,` 上一页，`Ctrl+.` 下一页
- **缩放**：`Ctrl+-` / `Ctrl++`
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+R`

切换学生时会**自动保存**当前这份的批改结果，不用担心丢失。

标记和评语的笔画大小会随页面大小自动调整——不管学生交的是 A4 还是高清大图，屏幕上看和导出的观感一致。

### 3. 设置满分

工具栏右侧的"满分"默认是 100，可按本次作业修改。超过满分的总分会标红提醒。

---

## 四、导出成果（重点）

批改完成后，点工具栏的 **导出Canvas**（或菜单里对应的导出项），会依次弹出几个对话框：

### 第 1 步：选成绩单 CSV

从 Canvas 的 Grades 页面导出成绩单 CSV，在这里选中它。

### 第 2 步：选要写入哪一列

软件会自动识别 CSV 里的作业列（表头形如 `第1次作业 (135353)`，括号里是作业 ID），用下拉框选本次的作业即可，不用手输 ID。

### 第 3 步：缺交登记（会先问你）

如果有学生这次没有成绩，会弹窗列出两类人：

- **尚未批改**：作业文件在，但你这次还没批
- **没有提交**：文件夹里根本找不到他的作业

⚠️ **批改途中如果还没批完，这里选"否"**，否则"尚未批改"的人会被写成 0 分。全部批完、确认要登记缺交时再选"是"。

### 第 4 步：选 ZIP 保存位置

最后选一个位置保存批改好的 PDF 压缩包。软件会预填好名字和位置（与作业文件夹同名、放在成绩单旁边），一般直接确定即可。

完成后：

- 得到一个 **ZIP 包**：里面是当前批次所有批改后的 PDF，文件名保持原样 → 直接上传到 Canvas / Moodle 的"批量上传提交项"，学生就能在提交评论里看到批注。
- **成绩单 CSV 已在原地更新**：分数填进了你选的那一列，如需同步到 Canvas，把这份 CSV 重新导入 Grades 即可。

> 导出用的是兼容 Moodle / Canvas 的打包方式（中文文件名带 UTF-8 标志），避免上传时报"请检查压缩文件"的错误。

## 五、批改结果存在哪里

软件会在作业文件夹下建一个 `done/` 目录保存进度，按批次分开：

```
我的作业/
├── 学生A.pdf
├── 学生B.pdf
└── done/
    ├── _batches.json              # 批次清单
    └── batch_xxx/                 # 某一次作业
        ├── 学生A.pdf              # 带批注的成品
        ├── 学生A.marks.json       # 标记坐标 + 评语（用于恢复）
        └── scores.csv             # 本次成绩汇总
```

`done/` 里是你的真实批改数据，已被 `.gitignore` 排除，不会进代码仓库。换电脑时想带走进度，把这个文件夹一起拷走即可。

## 六、多次作业不串档

软件会自动识别"是不是同一批作业"：

- 作业文件夹内容没变 → 视为同一批的续批，接着上次的记录
- 换了新一批提交（文件名/大小变了）→ 自动开新批次

也可以点工具栏的 **批次** 按钮手动切换或新建。

每份 `marks.json` 还会记住源文件的大小和修改时间，即使批次名相同，只要源 PDF 被换掉，旧的批改记录也不会被错误恢复。

## 七、常见问题

**Q：打开后是空的 / 找不到学生？**
确认用"设置路径"选的是作业文件夹，且里面的文件名开头是学号或 ID。

**Q：导出成绩时对不上学生？**
文件名开头那段数字要和 Canvas 成绩单里的 SIS Login ID / ID 一致。软件也支持用姓名匹配。导出后的弹窗会列出"未匹配"的人，照着调整文件名即可。

**Q：中文评语会变成乱码或小方块？**
软件会自动用内置中文字体，正常不会出现。若个别特殊符号无法显示会被自动跳过（比如 emoji）。

**Q：改了源码，之前导出的 PDF 会跟着变吗？**
不会。标记形状属于渲染逻辑，改代码只影响之后新导出的。已导出的成品如需更新，对相应学生重新点一次"完成"。

**Q：上传到 Moodle 报"重新上传提交项时出现问题"？**
请用软件导出的 ZIP（编码已处理），不要用 Windows 右键"压缩为 ZIP"重新打包——后者对中文文件名不友好。
